# Giáo Viên 4.0 - Trạm Vũ Trụ Tri Thức

Hệ sinh thái giáo dục số kết hợp khoa học nền tảng, công nghệ AI và mô phỏng trực quan 3D.

View your app in AI Studio: https://ai.studio/apps/05ba2abc-3d2e-4e73-b1db-24713f9e9086

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
